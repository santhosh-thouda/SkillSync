 SkillSync – Peer Learning &amp; Mentor Matching Platform Domain: Professional mentorship platform. 1. System Overview SkillSync is a multi-user platform that connects learners with mentors and enables peer learning. Users can search for mentors, book mentoring sessions, join learning groups, and review mentors after sessions. The platform must support: multi-role users real-time mentor discovery session booking and scheduling peer learning groups notifications and reminders scalable microservices architecture The backend system will be built using Spring Boot microservices architecture with event-driven communication via RabbitMQ . 2. Business Goals The platform aims to: help learners find mentors easily allow experts to monetize their skills enable peer learning communities provide reliable scheduling and communication maintain secure authentication and authorization 3. Key Actors 1. Learner A user who wants to learn new skills. Capabilities: search mentors request mentoring sessions join study groups rate mentors 2. Mentor An expert who teaches skills. Capabilities: create mentor profile list skills set availability accept/reject sessions receive ratings 3. Admin Platform administrator. Capabilities: manage users approve mentors moderate groups monitor platform activity 4. Functional Requirements 4.1 Authentication &amp; Authorization Users must be able to register and login securely. Features: user registration login with credentials JWT token generation role-based access control secure API access Supported roles: ROLE_LEARNER ROLE_MENTOR ROLE_ADMIN 4.2 User Profile Management Users maintain profiles containing personal and professional details. Features: create profile update profile add skills view profile upload profile image 4.3 Mentor Onboarding Mentors must apply before becoming active. Workflow: 1 User registers 2 User applies to become mentor 3 Admin reviews mentor request 4 Mentor profile activated Features: mentor application mentor profile creation mentor skill tagging mentor experience details 4.4 Skill Catalog Platform maintains a centralized skill list. Examples: Java Spring Boot Data Structures Machine Learning Features: create skills (admin) view skills tag skills to mentors 4.5 Mentor Discovery Learners should easily discover mentors. Filters include: skill rating experience price availability Features: search mentors view mentor profile view mentor ratings 4.6 Session Booking Learners can schedule mentoring sessions. Workflow: 1 learner selects mentor 2 learner requests session 3 mentor accepts or rejects 4 session scheduled Session states: REQUESTED ACCEPTED REJECTED COMPLETED CANCELLED 4.7 Peer Learning Groups Users can create study groups. Features: create learning group join group leave group group discussions Examples: Spring Boot Beginners DSA Interview Preparation Machine Learning Study Circle 4.8 Reviews and Ratings After sessions learners can review mentors. Features: submit rating submit review calculate average mentor rating 4.9 Notifications Users receive notifications for important events. Examples: session booked session accepted session reminder mentor approved Notifications are handled asynchronously via RabbitMQ . 5. Non Functional Requirements Scalability Microservices architecture allows independent scaling. Security Spring Security with JWT. Fault tolerance RabbitMQ ensures reliable event delivery. Maintainability Each service owns its business logic. Performance Service communication optimized using asynchronous messaging. 6. Microservices Breakdown 7.1 Auth Service Handles authentication. Responsibilities: register user login generate JWT validate JWT APIs POST /auth/register POST /auth/login POST /auth/refresh Database tables: users roles user_roles 7.2 User Service Handles user profiles. Responsibilities: create profile update profile fetch user details APIs GET /users/{id} PUT /users/{id} GET /users 7.3 Mentor Service Handles mentor specific logic. Responsibilities: mentor application mentor profile mentor availability mentor search APIs POST /mentors/apply GET /mentors GET /mentors/{id} PUT /mentors/{id}/availability 7.4 Skill Service Handles platform skills. Responsibilities: manage skills skill lookup APIs POST /skills GET /skills GET /skills/{id} 7.5 Session Service Handles mentorship sessions. Responsibilities: session request session acceptance session cancellation APIs POST /sessions PUT /sessions/{id}/accept PUT /sessions/{id}/reject PUT /sessions/{id}/cancel GET /sessions/user/{userId} 7.6 Group Service Handles peer learning groups. Responsibilities: create groups join groups manage group members APIs POST /groups POST /groups/{id}/join POST /groups/{id}/leave GET /groups GET /groups/{id} 7.7 Review Service Handles mentor ratings. Responsibilities: add review fetch mentor reviews calculate ratings APIs POST /reviews GET /reviews/mentor/{mentorId} 7.8 Notification Service Handles asynchronous notifications. Responsibilities: send email send push notifications process events from RabbitMQ 8. Event Driven Architecture (RabbitMQ) Events allow services to communicate without tight coupling. State Management — Angular Signals + NgRx auth.store.ts — NgRx SignalStore export const AuthStore = signalStore( { providedIn: 'root' }, withState&lt;AuthState&gt;({ user: null, token: null, isLoading: false }), withComputed(({ user }) =&gt; ({ isAuthenticated: computed(() =&gt; !!user()), isAdmin: computed(() =&gt; user()?.roles.includes('ROLE_ADMIN') ?? false), isMentor: computed(() =&gt; user()?.roles.includes('ROLE_MENTOR') ?? false), })), withMethods((store, authService = inject(AuthService)) =&gt; ({ async login(credentials: LoginRequest) { patchState(store, { isLoading: true }); const res = await authService.login(credentials); patchState(store, { user: res.user, token: res.token, isLoading: false }); }, logout() { patchState(store, { user: null, token: null }); } })) ); 6.
